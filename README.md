# Cricket Player Performance Evaluation

This Python program evaluates a cricket player's batting, bowling, and fielding performance based on user-provided statistics.

## Features

- Calculates batting strike rate
- Calculates bowling economy
- Evaluates batting performance
- Evaluates bowling performance
- Evaluates fielding performance
- Determines the overall all-rounder performance

## Concepts Used

- User input
- Variables
- Arithmetic operators
- `if-elif-else` statements
- Comparison operators
- Conditional logic

## Language

Python
